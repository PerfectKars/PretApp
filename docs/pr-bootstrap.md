# Préparer le socle FastAPI et React de PretApp

Le projet a besoin d'une base pour apprendre et développer les prêts de matériel sur quatre semaines. Cette branche prépare une API /health, une page React qui vérifie son contrat via le proxy Vite, un test HTTP, lint/formatage, une CI et un environnement Compose à trois services.

Validation effectuée : compilation syntaxique Python, configurations JSON, syntaxe shell/JS et diff Git. Installation et contrôles applicatifs non exécutés : accès DNS aux registres impossible et Docker absent. Versions directes proposées ; verrous transitifs à générer. **PR à conserver en brouillon jusqu'à installation, formatage, lint, pytest, build, Compose et CI verts.**

Périmètre : aucune fonctionnalité métier ni authentification, aucune migration encore. Documentation de règles et planning incluse. Développement assisté par IA ; exercice de compréhension étudiant en attente. Relier à l'issue GitHub correspondant à P01 après publication ; aucune revue indépendante revendiquée.
